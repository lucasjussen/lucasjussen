## 👩‍💻 Sobre mim

Atuo como TI generalista na **Monetali**, sendo responsável sozinho por uma operação de infraestrutura e sistemas que vai da administração de rede ao desenvolvimento de automações e integrações corporativas.

No dia a dia, cuido de:
- **Infraestrutura e redes**: administração UniFi, resolução de instabilidades de Wi-Fi, hardware e regras de tráfego.
- **Microsoft 365 / Entra ID**: gestão de contas, MFA, licenciamento, segurança e Conditional Access.
- **CRM e automação de processos**: desenvolvimento de SPAs e fluxos no **Bitrix24**, integrações com Meta Lead Ads, Google Ads e automações via **n8n**.
- **Desenvolvimento de sistemas próprios**: construção de aplicações internas para resolver problemas reais da empresa, unindo backend em Java com integrações via API.

Estou cursando **Análise e Desenvolvimento de Sistemas (ADS)** na PUCPR e uso meu trabalho na área de TI como laboratório prático para consolidar minha transição para desenvolvimento Java.
